# 🧮 Calculator Project

This project is a **web-based calculator** built with front-end technologies.  
It lets users perform basic arithmetic operations in a clean and interactive UI.

---

## 🔍 Features

- Addition, subtraction, multiplication, and division  
- Clear / reset functionality  
- Responsive layout for desktop and mobile  
- Visual feedback on button presses  
- Keyboard support (optional)  

---

## 🛠️ Technologies Used

- **HTML5** — to build the structure  
- **CSS3** — for styling and layout  
- **JavaScript** — to implement calculator logic and handle user interactions  

---

## 🚀 Getting Started

To run this project locally:

1. Open **Visual Studio Code**  
2. Create or open these files:  
   - `Calculator.html`  
   - `Calculator.css`  
   - `Calculator.js`  
3. Copy the project code into these files  
4. Use **Live Server** (a VS Code extension) or open `index.html` in your browser  
5. Enjoy using the calculator  

---

## 🎯 Project Goals

- Practice DOM manipulation and event handling  
- Reinforce logic for basic arithmetic operations  
- Build a user-friendly and responsive interface
